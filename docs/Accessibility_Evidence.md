# Accessibility Evidence

The assignment asks for before-and-after evidence of at least two improvements. The four named images in the `evidence` folder provide this:

- `Problem1.png`: the first accessibility review finding for colour contrast.
- `Fix1.png`: final desktop product page with dark readable controls, larger spacing and clear product grouping.
- `Problem2.png`: the first accessibility review finding for form errors.
- `Fix2.png`: final cart and checkout page with visible labels, error areas and invalid-field styling.

The final code also contains visible form labels, `aria-live` status messages, a skip link, alternative text and a reduced-motion rule.
